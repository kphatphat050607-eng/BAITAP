## Luu y ve Cau 1a

De ghi "so thuc" nhung lai yeu cau phan loai chan/le. Chan/le chi co nghia doi voi so nguyen; vi vay bai giai chi phan loai khi x la so nguyen (ke ca nhap dang 6.0), con so thuc khong nguyen se duoc thong bao ro.

## Kien thuc su dung

- Dieu kien: `if`, `while`
- Vong lap: `for`
- Kieu du lieu: `str`, `int`, `float`, `list`, `tuple`, `dict`
- Ham: `def`, `return`
- List: `append()`, `remove()`, `reverse()`
- Chuoi: `len()`, cat chuoi, `isdigit()`
